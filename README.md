# SCARA Dynamic Conveyor Interception System 🤖📦

An industrial-grade, zero-delay SCARA robotic arm system designed for real-time sorting on a moving conveyor belt. Powered by a custom multithreaded Python architecture and YOLOv8 computer vision, this system dynamically tracks, intercepts, and sorts objects by color (flavor) and size (capacity) without ever pausing the conveyor belt.

## ✨ Key Features

- **Zero-Delay Interception:** Multithreaded Python controller calculates real-time kinematics to intercept moving objects dynamically.
- **Dual Sorting Modes:** Sorts objects by Color (e.g., grape/violet, orange/orange, mango/yellow) or Size (e.g., 1L, 500ml, 250ml).
- **Auto-Homing Sequence:** Uses hardware limit switches on the elbows to find the `(0,0)` home position automatically on startup.
- **Edge-Clipping Protection:** Custom safe-zone boundaries in the vision worker prevent incorrect bounding box data from being saved.

## 📂 Repository Structure

| Path | Description |
| --- | --- |
| `arduino/` | `AccelStepper` C++ firmware for the main SCARA arm control |
| `esp/` | ESP32 code that runs the conveyor belt stepper and handles IR sensor interrupts |
| `main_scara_yolo.py` | Core multithreaded controller integrating Vision (YOLO) and Hardware (Serial) |
| `radius_calibrator.py` | Utility to calibrate the pixel radius that separates "Large" from "Small" objects |
| `threshold.txt` | Stores the threshold value generated by the calibrator |
| `runs/`, `test/`, `train/`, `valid/`, `data.yaml` | Directories and config for custom YOLOv8 model training |
| `yolov8n.pt` | Pre-trained YOLOv8 weights used for object detection |

## 🛠️ Hardware Requirements

**SCARA Arm**

- 4x NEMA 17 Stepper Motors (Base, Elbow 1, Z-Axis, Elbow 2)
- 3x TB6612FNG and 1x A4988 Stepper Drivers
- 1x MG996R / SG90 Servo Motor (gripper jaw)
- 2x Limit Switches (auto-homing on Elbow 1 and Elbow 2)
- Arduino UNO / Mega (runs the arm kinematics)

**Conveyor System**

- 1x NEMA 17 Stepper Motor and 1x A4988 Driver
- 1x IR Obstacle Avoidance Sensor (trigger module)
- ESP32 (runs the conveyor logic and sends IR interrupts)

## 🚀 Installation & Setup

1. **Clone the repository**

   ```bash
   git clone https://github.com/see-yaam/Orion-X-SCARA-and-Conveyor.git
   cd Orion-X-SCARA-and-Conveyor
   ```

2. **Install Python dependencies**

   ```bash
   pip install opencv-python numpy pyserial ultralytics
   ```

3. **Flash the microcontrollers**

   - Open the `arduino/` folder and upload the firmware to your Arduino (default port: `COM9`).
   - Open the `esp/` folder and upload the firmware to your ESP32 (default port: `COM10`).

   > **Note:** If your COM ports are different, update them in `main_scara_yolo.py`.

## 🎮 How to Run

### Step 1: Size Calibration (optional but recommended)

Run the calibrator to set the pixel radius for Large vs Small objects:

```bash
python radius_calibrator.py
```

1. Place a **small** object and press `1`.
2. Place a **large** object and press `2`.
3. Press `Enter` to save the result to `threshold.txt`.

### Step 2: Start the Main System

```bash
python main_scara_yolo.py
```

### Step 3: Operation Controls (Camera Window)

**Startup**

| Key | Action |
| --- | --- |
| `y` | Start the Auto-Homing sequence (moves to limit switches to set `0,0`) |
| `n` | Skip homing (if the arm is already manually placed at `0,0`) |
| `s` | Move the arm to the Standby position `(0, 470)` over the conveyor |

**While running**

| Key | Action |
| --- | --- |
| `c` | Start conveyor and sort by **Color** |
| `s` | Start conveyor and sort by **Size** |
| `b` | Emergency stop and return to Standby `(0, 470)` |
| `h` | Full reset and return to Home limit switches `(0,0)` |
| `Esc` | Close the program safely |
